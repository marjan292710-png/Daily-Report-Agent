# 📰 Daily Report Agent

An AI-powered news report generator built with Python, Gemini, SerpAPI, and Streamlit.

The Daily Report Agent searches the web for current information on a topic and uses AI to turn the search results into a clear, structured report.

## 🌐 Live Website

[Open the Daily Report Agent](https://daily-report-agent-neh6efu7oaixvpw3wswrce.streamlit.app)

## 🚀 Features

- 🔎 Real-time web search using SerpAPI
- 🤖 AI-generated reports using Gemini
- 📰 Key stories and summaries
- 🎯 Action items and opportunities
- ✏️ Custom report topics
- 📥 Download generated reports
- 🌐 Public Streamlit web application
- 🔐 API keys protected using Streamlit Secrets

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- SerpAPI

## 📋 Example Topics

You can generate reports about:

- Latest technology news
- Artificial intelligence
- Minecraft news
- Python programming
- AI business opportunities
- Freelancing
- Your own custom topic

## 🔐 Security

API keys are stored using Streamlit Secrets and are not included in the GitHub repository.

The `.streamlit/secrets.toml` file is excluded using `.gitignore`.
